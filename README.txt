ساختار پوشه:

cafe_digital_menu/

    index.html
    style.css
    script.js
    README.txt


روش اجرا:

1- ابتدا پوشه پروژه را در کامپیوتر ایجاد کنید.

2- چهار فایل بالا را داخل آن قرار دهید.

3- پوشه را با Visual Studio Code باز کنید.

4- فایل index.html را اجرا کنید.

5- برای مشاهده منو از مرورگر استفاده کنید.


تغییر محصولات:

برای تغییر نام محصولات وارد فایل script.js شوید.

محصولات بار گرم در قسمت hot قرار دارند.

محصولات بار سرد در قسمت cold قرار دارند.


تغییر قیمت:

مثال:

{ name: "لاته", price: "۸۵٬۰۰۰ تومان" }

برای نمایش قیمت به جای عبارت استعلام،
مقدار قیمت را وارد کنید.


تغییر رنگ‌ها:

برای تغییر رنگ طلایی و مشکی وارد style.css شوید.

رنگ‌های اصلی در ابتدای فایل تعریف شده‌اند.


نکته مهم:

برای نمایش فونت فارسی Vazirmatn و فونت Playfair Display
اتصال اینترنت لازم است.

بدون اینترنت نیز ساختار اصلی منو اجرا می‌شود،
اما فونت جایگزین سیستم نمایش داده خواهد شد.
